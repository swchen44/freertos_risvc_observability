如何判讀

64-byte line 只讀寫 4 bytes 就被逐出，該次駐留的使用比例為 6.25%。把會一起使用的資料放在一起，能提高空間區域性；但拆小 function／變數本身不保證改善。

追蹤結束時仍駐留的未用 bytes 另列，不能視為已證明的浪費。這個模型沒有 prefetch、writeback、instruction traffic 或 bus timing；不可把 miss 減少比例當成時間加速比例。

原始 PSF 保留 CACHE_BEGIN／CACHE_END；cache JSON 以 PSF SHA-256 連結。本頁目前顯示整段工作區域，沒有逐事件 PSF 時間軸或 L1I 死碼判定。
