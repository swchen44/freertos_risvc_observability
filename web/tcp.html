這份結果代表什麼？

Zero-copy 的 payload 必須持續有效，直到 TCP ACK 或連線清理。本測試使用整段 session 不變的 buffer，並驗證 ACK 遺失後仍能重傳正確資料。

一般傳送與重傳成本分開看。減少 copy 不保證每條路徑都更快；cache miss 也不能直接換算成時間。

目前測試沒有 NIC / DMA / RTT 模型，不能重現 Wi-Fi Mbps。未追蹤的 ACK 區段會改變真實 cache 狀態，所以每個量測區段各自 cold-start。
